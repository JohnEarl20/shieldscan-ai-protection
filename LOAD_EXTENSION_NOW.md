# 🚀 Load ShieldScan Extension - Step by Step

## You're on the right page! Now follow these exact steps:

### 1. ✅ You're already on chrome://extensions/ - GOOD!

### 2. 🔧 Enable Developer Mode
- Look at the **top right** of the extensions page
- Find the toggle switch that says "Developer mode"
- **Click it to turn it ON** (it should turn blue/green)

### 3. 📁 Load the Extension
After enabling Developer mode, you'll see new buttons appear:
- Click the **"Load unpacked"** button (should appear at top left)
- A file browser will open
- Navigate to your project folder: `C:\AI Scam Protection Platform`
- Select the **`browser_extension`** folder (not a file, the whole folder)
- Click **"Select Folder"** or **"Open"**

### 4. ✅ Extension Should Appear
The ShieldScan extension will appear in your extensions list with:
- Name: "AI Scam Protection"
- Version: "0.2.0"
- Description: "Advanced browser protection with real threat detection..."

### 5. 🎯 Test the Extension
Once loaded, you can:
- Click on the extension icon in Chrome toolbar
- Or open the dashboard directly by clicking "Details" → "Extension options"
- Or navigate to the extension's dashboard page

## 🔍 If You Don't See "Load unpacked" Button:
- Make sure Developer mode toggle is ON (top right)
- Refresh the extensions page (F5)
- The toggle should be blue/green when enabled

## 📂 Correct Folder Structure:
Make sure you're selecting the `browser_extension` folder that contains:
- dashboard.html
- manifest.json
- background.js
- dashboard.js
- etc.

## 🚨 Common Issues:
1. **Developer mode not enabled** - Toggle must be ON
2. **Wrong folder selected** - Select `browser_extension` folder, not the parent folder
3. **Missing manifest.json** - Make sure all files are present
