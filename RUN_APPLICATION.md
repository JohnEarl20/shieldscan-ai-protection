## 🆘 TROUBLESHOOTING

### Extension Won't Load
**Solution**:
1. Make sure you selected the `browser_extension` folder
2. Make sure `manifest.json` is in the root
3. Check that all files are present
4. Try refreshing the extensions page (F5)
5. Try restarting Chrome

### Dashboard Won't Open
**Solution**:
1. Check if extension is enabled
2. Try clicking extension icon again
3. Check browser console for errors (F12)
4. Try refreshing dashboard (F5)
5. Try reloading extension

### Threat Detection Not Working
**Solution**:
1. Try with valid URLs
2. Check browser console (F12)
3. Try refreshing dashboard (F5)
4. Try reloading extension

### Real-Time Updates Not Working
**Solution**:
1. Wait 3-5 seconds (updates on intervals)
2. Check browser console (F12)
3. Try refreshing dashboard (F5)
4. Try reloading extension
